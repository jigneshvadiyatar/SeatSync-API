
# SeatSync Backend 🎟️

SeatSync is a real-time event ticket booking and seat reservation platform inspired by applications like BookMyShow.

This repository contains the backend of SeatSync, built using **Node.js, Express.js, and JavaScript**.

The platform is designed to handle event management, seat availability, concurrent reservations, secure payments, and real-time booking updates.

### Tech Stack

- **Backend:** Node.js, Express.js, JavaScript (ES Modules)
- **Database:** PostgreSQL
- **Caching & Seat Holds:** Redis
- **Message Broker:** RabbitMQ
- **Real-Time Communication:** Socket.IO
- **Authentication:** Google OAuth 2.0
- **Payments:** Stripe
- **Containerization:** Docker & Docker Compose

### Key Features (Planned)

- Event, venue, and show management
- Real-time seat availability and reservations
- Prevention of double booking using database transactions
- Temporary seat holds with Redis
- Secure payment processing with Stripe
- Asynchronous background processing with RabbitMQ
- Google authentication and role-based access control
- Booking history and management
